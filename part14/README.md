# Books REST API (CBE204 Week 4)

## 1. Project Description
This project is a simple REST API built with Node.js and Express.js. It manages a collection of books, allowing users to retrieve all books, retrieve a specific book by its ID, and add new books to the collection using in-memory data storage.

## 2. Installation
To install and set up this project on your local machine, follow these steps:
1. Clone or download the repository.
2. Open your terminal and navigate to the project folder (`week04-api`).
